# Godot browser

A stupid and silly browser made with godot. It does not support JS or CSS and works best with simple websites.

<img src="https://cdn.hackclub.com/01a0e3df-3317-70f5-8cc6-a118a2159c90/godot_browser_homepage.png" height="350">

_The home page of the browser (with no customizing applied)_

## Get the browser
Download the latest release from [Godot-browser/releases](https://github.com/Trulle1234/Godot-browser/releases)

## Clone the project
```
git clone https://github.com/Trulle1234/Godot-browser/
```
And then import it to godot!
